# Contributing to Windows Connection Order

Thanks for considering a contribution. Bug reports, documentation fixes, translations, design feedback, and pull requests are welcome.

## Before opening a pull request

- Discuss substantial changes in an issue first.
- Keep each pull request focused.
- Do not add generated build output, private credentials, certificates, or signing keys.
- Make sure you have the right to submit every part of your contribution.
